RADIUM V58 — CATEGORY RANKINGS AND ANYO TIE-BREAK FIX

Changes included:
1. Combative category results now show official standings per category, including placement, medal, athlete, team/school, matches, wins, losses, and remarks.
2. Single-elimination placement derives from completed bracket progression: 1st Gold, 2nd Silver, 3rd and 4th Bronze, then 5th onward based on the round eliminated. Placements that cannot yet be determined remain pending.
3. Completed Combative match scores remain listed separately beneath the category standings.
4. Anyo standings group each performer/entry and use its latest saved performance for ranking while preserving the attempt count. Judge scores, average, deductions, final score, time, medal, rank, and remarks appear on screen and printouts.
5. Ties that affect Anyo medal positions are flagged for repeat performance. The repeat button opens the Anyo scoreboard for that exact entry. If a repeat still ties within medal positions, another repeat is required.
6. Equal Anyo scores outside medal positions retain the same rank and do not require a repeat.
7. Printing selected/all categories includes standings, medal remarks, and the detailed match log for Combative.
8. Anyo scoreboard respects a requested competitor ID when opened for a repeat performance and labels the scoreboard as repeat mode.
9. Existing Supabase schema and Anyo/Combative data separation are preserved.

Validation: JavaScript syntax checked; ZIP integrity checked after packaging. A live Supabase tournament and actual print dialog still need an in-app acceptance test.
